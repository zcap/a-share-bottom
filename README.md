# A股 · 距历史最低

这个项目每天自动计算全部 A 股（沪深 + 北交所，不含已退市）的：

> **比值 = 当前股价 ÷ 上市以来最低价**（等比后复权，历史最低价包含发行价）

结果发布成一个网页，手机和电脑都能打开。数据在每个交易日晚上自动更新；盘中点“获取实时价”可以看到最新比值。

整个项目运行在 GitHub 上，不需要服务器，也不收费。

## 一、部署步骤

大约需要 15 分钟。首次构建数据另需 1～3 小时，期间不用守着。

### 1. 注册 GitHub 账号

打开 https://github.com 注册，已有账号就直接登录。

### 2. 新建仓库

右上角 **+** → **New repository**：

- Repository name：随便起，例如 `a-share-bottom`（会出现在网址里）
- 选 **Public**（公开）。私有仓库发布网页需要付费
- 点 **Create repository**

### 3. 上传代码

在新仓库页面点 **uploading an existing file**，把解压后文件夹里的**全部内容**拖进去，然后点 **Commit changes**。

上传后检查仓库里有没有 `.github/workflows/update.yml`。以 `.` 开头的文件夹在 Mac 上默认隐藏，可能没传上去。如果没有，就手动建一个：

1. 点 **Add file** → **Create new file**
2. 文件名一栏输入 `.github/workflows/update.yml`（输入 `/` 时会自动变成文件夹）
3. 把压缩包里这个文件的内容粘贴进去，点 **Commit changes**

### 4. 打开网页发布功能

仓库 **Settings** → 左侧 **Pages** → **Build and deployment** 下的 **Source** 选 **GitHub Actions**。

### 5. 检查数据源能不能访问

1. 仓库顶部点 **Actions**。如果提示要启用 workflows，点绿色按钮启用
2. 左侧选 **更新数据并发布网页** → 右侧 **Run workflow** → mode 选 **probe** → 点 **Run workflow**
3. 一两分钟后点进这次运行，在 **Summary** 页面查看检查结果：
   - BaoStock 相关全部 ✅：可以继续
   - BaoStock 有 ❌：沪深数据拿不到，网页无法更新。把 Summary 截图发给我
   - 其他项有 ❌：不影响沪深数据，只是北交所、实时价或发行价会降级

### 6. 首次构建

再点一次 **Run workflow**，mode 选 **rebuild**。它会下载 5000 多只股票的完整历史，大约 1～3 小时。

完成后访问：`https://<你的用户名>.github.io/<仓库名>/`

运行超过 5 小时会自动保存进度并结束，下一次运行会接着做，不用管。

### 7. 之后全自动

| 北京时间 | 做什么 | 大约用时 |
|---|---|---|
| 周一至周五 18:40 | 每日更新（BaoStock 当天数据入库后） | 2 分钟 |
| 周一至周五 22:40 | 补跑一次，以防 BaoStock 入库晚 | 2 分钟 |
| 周六 09:17 | 每周核对：只核对每只股票的复权因子，对不上的才重算 | 1 小时 |
| 每月第一个周六 09:17 | 完整重建：重新下载全部历史，兜底数据源事后修正历史 | 约 6～7 小时，分两次运行 |
| 周日 09:17 | 接着完成周六没跑完的完整重建 | 1～2 小时 |

GitHub 定时任务通常会晚十几分钟到几个小时触发，属于正常现象，每天的数据仍会更新。漏跑了几天也没关系，下次运行会按天补齐；漏跑超过 15 个交易日会自动改成全量重建。

## 二、常见问题

**运行失败（红色 ✕）怎么办？**
点进那次运行看 Summary 和日志。网页会保留上一次成功的数据，不会坏掉。偶发的网络失败等下一次定时运行即可；连续失败请把日志发给我。

**收到 GitHub 邮件说定时任务被停用？**
公开仓库 60 天没有活动时，GitHub 会暂停定时任务。到 Actions 页面点 **Enable workflow** 即可恢复。

**国内打开 github.io 很慢？**
可以免费把同一个仓库再部署到 Cloudflare Pages，作为备用地址。需要的话我可以补充步骤。

**想改更新时间？**
编辑 `.github/workflows/update.yml` 里的 `cron` 行。注意那里写的是 UTC 时间，等于北京时间减 8 小时。

## 三、实现方案

### 数据源（全部免费、无需注册）

| 用途 | 来源 | 说明 |
|---|---|---|
| 沪深股票列表、上市日期 | BaoStock `query_stock_basic` | 每次运行都刷新，自动加入新股、剔除退市股 |
| 沪深完整历史 | BaoStock `query_history_k_data_plus` + `query_adjust_factor` | 不复权日线（含前收盘价）+ 官方后复权因子 |
| 沪深每日增量 | BaoStock `query_daily_history_k_AStock` + `query_daily_adjust_factor` | 一次请求拿到全市场某一天的数据 |
| 北交所 | 北交所官网列表 + 腾讯日线 / 腾讯实时行情 | BaoStock 不覆盖北交所 |
| 发行价 | 东方财富数据中心（2010 年后上市的股票 + 北交所） | 更早上市的股票用上市首日前收盘价推断 |
| 网页实时价 | 腾讯行情 `qt.gtimg.cn` | 由你的浏览器直接请求 |

没有用东方财富的行情接口：它从 2026 年 10 月底开始，连续请求几次就会限流封 IP。

### 计算口径

- **复权**：等比后复权。上市首日因子为 1，每次分红、送转、配股后，因子乘以“前一日收盘价 ÷ 除权除息参考价”。
- **为什么用后复权**：
  - 上市首日因子为 1，发行价可以直接和后复权价比较；
  - 历史价格不会因为新的分红而改变，所以每天只需增量更新；
  - 不会像前复权那样出现负价。
- **比值**：当前后复权价 ÷ min(上市以来每日最低价的后复权值, 发行价)。等比复权下，这个比值和用前复权价算出的完全一样。
- **两种最低价口径**：可以用日内最低价，也可以用收盘价。网页上可以切换，也可以选择是否计入发行价。

### 每只股票只保存一行“状态”

不保存全部历史 K 线，每只股票只记录这些字段：

- 当前复权因子
- 最后收盘价
- 历史最低价（日内最低、收盘两种口径）及对应日期
- 发行价

每天来一根新 K 线，就更新一次：

1. 如果当天是除权除息日，更新复权因子。
2. 计算当天最低价、收盘价的后复权值，比旧的最低值低就替换。

全市场的状态是一个约 1 MB 的压缩表格，存在仓库的 `data` 分支，每次只保留一个提交，仓库不会变大。

### 容错设计

- **可重复运行**：同一天的数据重复处理会自动跳过，多跑几次结果不变。
- **漏跑补齐**：按交易日历逐日补；漏太多就自动全量重建。
- **数据异常保护**：某天有超过 15% 的股票“前收盘价对不上”，说明数据源有问题，放弃当天更新、保持原状。
- **缺数据不猜**：某只股票当天在全市场数据里缺失时，不猜测，改用它的完整历史单独重算。
- **停牌期间除权**：复牌日用除权前的因子核对参考价，不会重复复权。
- **每周核对**：后复权价一旦算出就不再变化，所以只要每只股票的“当前复权因子”和 BaoStock 一致，就说明没有漏算除权。每周只核对因子（每只一次小查询），对不上的才重算；每月再完整重建一次兜底。
- **只用完整入库的数据**：BaoStock 傍晚陆续入库，全市场单日数据不到 95% 时视为当天还没入库完，等下一次运行。
- **可续跑**：首次构建可分多次完成，进度自动保存。

### 网页里的实时价

网页本身是静态的。数据文件 `data/latest.json` 里存了每只股票的收盘价、复权因子和历史最低价。点“获取实时价”时，浏览器直接向腾讯行情请求全市场最新价（约 90 次小请求），然后在页面里重新计算：

- 今天的最低价也计入历史最低；
- 今天如果是除权除息日，根据腾讯给出的昨收（参考价）自动调整因子。

### 目录结构

```
bottom/            计算程序（Python）
  engine.py        核心计算：复权、历史最低、比值（纯计算，有单元测试）
  src_baostock.py  BaoStock 数据源
  src_other.py     腾讯行情、北交所列表、东方财富发行价
  pipeline.py      流程：全量构建、每日增量、补跑、容错
  export.py        生成网页数据（JSON + CSV）
  probe.py         数据源检查
web/               网页（index.html / app.js / style.css）
scripts/state.sh   计算状态的取回与保存（data 分支）
tests/             模拟市场的单元测试
.github/workflows/update.yml   定时任务与网页发布
```

```bash
python -m bottom daily     # 计算（第一次会自动全量构建），结果在 site/ 目录
python -m pytest tests     # 运行测试
```
